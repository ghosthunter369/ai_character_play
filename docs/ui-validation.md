# 柔和工作台界面改版

2026-10-22。用户批准暖灰底、白色面板与低饱和绿色的SaaS风格，并授权本次合并至master。

## 改动

- 统一颜色、字体、边框和焦点样式，去除主要页面的紫色渐变、发光与漂浮装饰。
- 导航在窄屏显示为两行；登录、注册使用单列表单和真实字段标签，移除含硬编码账号的体验登录入口。
- 精选/发现共享RoleCard，保留原API事件，使用小头像、介绍和明确按钮；移除随机浏览量、随机聊天次数及重复的浮动助手入口。
- 聊天侧栏精简，窄屏改为角色选择器；消息区独立滚动，输入与语音操作保留在底部。
- 语音识别、输出选择、按轮发言、打断、新会话、反馈与实际播放处理器保留。输入长度与服务器2000字限制对齐。
- 注册字段prop与已有model/rules对应，空表单只显示字段错误；账户菜单调用现有退出API，成功后才清除本地用户状态。

## 验证

- 生产语音状态机16项测试通过，Docker内Vite生产构建通过。
- HTTP注册/登录/Redis会话/角色列表通过；独立测试会话实际退出后无法继续读取登录用户。
- 重建web后运行真实WS回归：PCM→Whisper→Qwen→WAV、反馈确认、取消重发均通过。
- 浏览器实际核对登录、注册、角色卡片入口、文字/语音切换、供应商选择、文字提交→真实回复→播放回调、反馈已记录、结束通话。
- 空注册在修复前只触发邮箱规则；修复后账号、邮箱、密码、确认密码均显示对应必填提示。
- 当前浏览器609×884：登录页documentWidth=609；语音页documentWidth=609、documentHeight=884，控件底部均在视口内。其他尺寸由媒体查询适配，未声称已做桌面全尺寸或真机测试。
- 独立审查未发现遗留确认的重要问题；类型检查仍44项，去掉行号后的诊断与改版前完全相同。新RoleCard、布局与语音组件未引入类型诊断；全仓类型检查没有通过。
